# 사례 기반 이상탐지·원인 분석 Agent

> 준비 단계 저장소입니다. 현재는 범위와 학습 미션 문서만 있으며 실행 가능한 프로그램·학습 결과는 아직 없습니다.

[첫 미션](MISSION-01.md) · [진행 기록](../PROGRESS.md) · [기록 양식](RECORD-TEMPLATE.md)

상태: 연구 범위·실험 설계. 면접 활용: 제외, 직접 구현·평가·설명 확인 후 재검토.

## 연구 목표

실제로 발생한 오류 사례를 참고해 소프트웨어로 예상 오류 상황을 재현하고, 이상 검출과 원인 분석, 설명·보고서 생성의 성능을 평가합니다. 결과를 논문 형식으로 정리합니다.

- 하드웨어 제작·실제 센서 설치·XR은 제외합니다.
- 시뮬레이션, 공개 데이터 또는 기존 기록 데이터로 동작합니다.
- Agent, 자동 원인 분석, 설명, 사건별 보고서 자동 생성은 필수 범위입니다.
- 사건별 자동 보고서와 연구자가 작성하는 논문은 별개 결과물입니다.
- 대상 시스템·첫 오류·변수와 생성 수식은 아직 확정되지 않았습니다.

## 계획 흐름

사례 조사 → 정상/오류 생성 또는 재생 → Detection → Analysis → Explanation → Report

| 역할 | 계획 입력 | 계획 출력 |
|---|---|---|
| Detection | 관측 가능한 다변량 시계열 | 이상 점수·구간·이벤트 |
| Analysis | 관측값, 분석 도구 결과, 사례 근거 | 원인 후보·순위·근거·불확실성 |
| Explanation | 검증된 분석 결과 | 근거와 연결된 자연어 설명 |
| Report | 이벤트·원인 후보·설명 | 사건별 분석 보고서 |

수치 분석은 계산 코드로 검증합니다. Agent마다 도구·상태·입출력·실패 처리를 명세하며 모든 계산을 LLM에 맡기지 않습니다.

## 구현·연구 단계

- [ ] 대상 시스템·관측 변수·단위·정상 동작 정의.
- [ ] 출처가 있는 실제 사례와 재현 가정을 연결.
- [ ] 정상 생성기와 오류 강도·지속 시간·정답 기록 구현.
- [ ] 실행/생성 단위 데이터 분리 후 시간 창 구성.
- [ ] 임계값 방식·기준 모델·AutoEncoder 비교.
- [ ] 원인 분석·설명·보고서 Agent 연결.
- [ ] 구성요소별 비교와 전체 시스템 평가.
- [ ] 실패·제한 조건을 포함한 논문 형식 보고서 작성.

## 평가와 재현 원칙

| 대상 | 평가 내용 |
|---|---|
| 이상탐지 | 이벤트 검출률, 정상 구간 오탐, 검출 지연, 유형·강도별 성능 |
| 원인 분석 | 정답 원인의 후보 포함·순위, 근거 적절성, 판단 보류 |
| 설명·보고서 | 관측 결과 일치, 필수 항목 누락, 근거 없는 주장 |
| 시스템 | 실패 처리, 실행 재현, 처리 시간 |

평가용 오류 이름·원인·발생 구간은 별도 보관하고 모델/Agent에 노출하지 않습니다. 파일명이나 프롬프트에 정답이 들어가지 않게 확인합니다. 임계값은 검증 자료에서 결정합니다.

실제 사고 측정과 사례 기반 합성 데이터를 구분하고, 합성 시나리오 성능을 현장 성능으로 일반화하지 않습니다. 복원 오차가 큰 변수만으로 물리적 원인을 확정하지 않습니다.

## 현재 결과

시나리오·모델·Agent 성능: 미측정. 논문: 작성 준비. 현재 저장소에는 준비 문서만 있으며 실행 코드·데모는 아직 없습니다.

첫 미션: 대상 시스템, 관측 변수 3~4개, 첫 오류의 원리, 사례 근거와 가정, 평가자만 볼 정답을 한 장의 설계 카드로 정리합니다.
