# 사례 기반 이상탐지·분석 Agent

**딥러닝 · 실험 평가 · Agent**

사례 기반 오류 시나리오를 탐지하고 원인 후보·설명·보고서를 제공하는 소프트웨어 연구 프로젝트.

> **현재 단계 · 연구·실험 설계**  
> 현재 공개 자료는 설계와 첫 미션 문서입니다. 실행 코드·데모·평가 결과는 구현 후 추가합니다.

[상세 계획](docs/PROJECT-PLAN.md) · [진행 기록](PROGRESS.md) · [첫 미션](docs/MISSION-01.md)

## 해결하려는 문제

오류를 발견하는 것에서 나아가, 어떤 관측 변화가 나타났고 가능한 원인은 무엇인지 근거와 함께 확인하는 시스템을 연구합니다.

| 입력 | 목표 출력 |
|---|---|
| 사례를 반영한 소프트웨어 시계열과 관측 가능한 상태 | 이상 구간, 원인 후보와 근거, 사건별 자동 보고서 |

## 구현할 흐름

```text
사례·시나리오 → 이상탐지 → 원인 후보 분석 → 근거 기반 설명 → 자동 보고서
```

- 소프트웨어 정상·오류 시나리오 생성과 평가 전용 정답 관리.
- 임계값 방식·기준 모델·AutoEncoder 비교.
- 탐지·원인 분석·설명·보고서 Agent와 논문 형식 연구 보고서.

**적용 예정 기술:** Python · NumPy/Pandas · scikit-learn · PyTorch · LLM/Agent  
기술 목록은 설계 방향이며 현재 구현 완료 목록이 아닙니다.

## 검증할 내용

- 오류 유형·강도별 검출률, 오탐, 검출 지연.
- 원인 후보의 정확성과 근거 일치.
- 보고서 누락·근거 없는 주장과 구성요소별 비교.

하드웨어 제작·실제 센서 설치·XR은 제외합니다. 합성 시나리오 평가와 실제 현장 성능을 구분하며, 평가 정답은 모델·Agent 입력에 제공하지 않습니다.
